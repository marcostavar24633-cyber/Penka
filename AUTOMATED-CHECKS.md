# Автоматическая проверка PENKA

При каждом push в `main`, pull request в `main` или ручном запуске GitHub Actions выполняет `python tools/check_site.py`.

Проверка не требует сторонних Python-пакетов и не меняет файлы сайта. Если найдены ошибки в структуре HTML или отсутствующие локальные ресурсы, workflow завершится с ошибкой, чтобы проблему было видно до публикации.

Оптимизация WebP остаётся отдельной локальной операцией: GitHub Actions не заменяет исходные изображения автоматически.
