# Оптимизация изображений PENKA

Скрипт создаёт оптимизированные WebP-копии и **не изменяет оригиналы**.

## Запуск на Windows

1. Скачайте репозиторий PENKA с GitHub (Code → Download ZIP) и распакуйте архив.
2. Откройте PowerShell в папке проекта.
3. Установите библиотеку:

   ```powershell
   py -m pip install Pillow
   ```

4. Запустите:

   ```powershell
   py tools/optimize_images.py
   ```

Результат появится в `optimized/img/`. Скрипт выведет размер каждого файла и общую экономию.

## Параметры

- По умолчанию WebP quality 80, максимальная сторона 1800 px.
- Более сильное сжатие:

  ```powershell
  py tools/optimize_images.py --quality 76 --max-width 1600
  ```

- Более бережное сжатие:

  ```powershell
  py tools/optimize_images.py --quality 84 --max-width 2000
  ```

## Как заменить изображения на сайте

1. Сначала сравните оригиналы и файлы из `optimized/img/` визуально, особенно hero и фотографии еды.
2. Если качество приемлемо, скопируйте файлы из `optimized/img/` в `img/` с заменой соответствующих файлов.
3. Проверьте локально главную страницу и мобильную версию.
4. Загрузите обновлённые бинарные файлы в репозиторий с теми же именами. HTML менять не требуется.

Скрипт не удаляет оригиналы и не обещает фиксированного процента экономии: результат зависит от исходных изображений. После замены повторите Lighthouse на мобильном устройстве.

## Ограничение GitHub Pages

Обычный GitHub Pages не позволяет задать произвольные HTTP-заголовки кеширования для отдельных файлов. Поэтому предупреждение Lighthouse о cache lifetime может остаться даже после сжатия изображений. Для управления этими заголовками потребуется CDN или хостинг с настройкой cache headers.
