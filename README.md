# Пенка — концепция сайта кофейни

Демонстрационный одностраничный сайт вымышленной кофейни для портфолио веб-дизайна.

## Что демонстрирует проект
- Адаптивный лендинг с меню-концепцией и фотогалереей.
- Светлую и тёмную цветовые темы с сохранением выбора.
- Навигацию с клавиатурным управлением вкладками.
- Адаптивные карточки, состояния фокуса и поддержку системной настройки уменьшения движения.
- Базовую SEO-разметку, Open Graph, robots.txt и sitemap.xml.

## Технологии
- HTML, CSS и JavaScript без сборщика.
- Изображения хранятся в каталоге `img/`.
- Шрифты Manrope, Playfair Display и Marck Script подключаются через Google Fonts.

## Публикация
Сайт размещается через GitHub Pages из ветки `main`, каталог `/ (root)`.

## Важно
«Пенка» — вымышленная кофейня. Названия позиций и цены представлены исключительно как часть дизайн-концепции. У проекта нет реального адреса, телефона, точки продаж или действующих услуг.
