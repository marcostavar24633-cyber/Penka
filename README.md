# ПЕНКА — Coffee · Bakery · Design

Премиальная визуальная концепция specialty coffee-бренда для портфолио.

## О проекте

ПЕНКА — вымышленная кофейня и демонстрационный коммерческий проект. Сайт передаёт атмосферу современной европейской coffee-культуры через редакционную типографику, натуральную палитру, крупные фотографии и лаконичную композицию.

**Важно:** это концепт, а не действующее заведение. Название, позиции меню и цены демонстрационные. Реального адреса, телефона, точки продаж, отзывов, наград и онлайн-заказа нет.

## Что реализовано

- Имиджевый первый экран с фирменной подписью PENKA COFFEE · BAKERY · DESIGN.
- Редакционный блок о философии бренда.
- Меню с пятью интерактивными категориями: кофе, авторские напитки, чай, выпечка и десерты.
- Галерея с полноэкранным просмотром, клавиатурной навигацией и возвратом фокуса.
- Светлая и тёмная темы с сохранением выбора.
- Адаптивное мобильное меню и плавающий переход к меню.
- Анимации с поддержкой `prefers-reduced-motion`.
- SEO-метаданные, Open Graph, sitemap.xml и robots.txt без ложной разметки LocalBusiness.

## Технологии

- Семантические HTML, CSS и vanilla JavaScript.
- Без сборщика, платных API, отдельного сервера и базы данных.
- Оптимизированные локальные WebP-изображения в `img/`.
- Шрифты Cormorant Garamond, Manrope, Marck Script и Playfair Display через Google Fonts.
