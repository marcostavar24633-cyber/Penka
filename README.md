# Пенка — кофейня на углу

Одностраничный лендинг кофейни «Пенка»: меню с вкладками, атмосфера, как нас найти.

- Оформлен по дизайн-системе «Слопай букет»: светлая тема (персик · золото · красный) по умолчанию и тёмная (чёрный · золото); переключатель в шапке, выбор запоминается.
- Один файл `index.html` без сборки и зависимостей; фото — в `img/`.
- Шрифты Playfair Display и Manrope подключаются с Google Fonts.
- Фон — полупрозрачные векторные кофейные зёрна разной обжарки (от зелёного до тёмного), медленно плавают; без анимации при «уменьшить движение».

Открыть локально — просто `index.html` в браузере. Чтобы опубликовать бесплатно: Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.

Концепт-сайт: кофейня вымышленная, меню, цены, адрес и телефон придуманы, фотографии сгенерированы ИИ.
