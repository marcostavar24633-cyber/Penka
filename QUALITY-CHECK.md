# Проверка качества статического сайта

В репозитории есть независимый от сторонних библиотек чекер:

```bash
python tools/check_site.py
```

Он проверяет:
- наличие заголовка страницы и meta description;
- ровно один H1;
- повторяющиеся HTML id;
- изображения без `src` или `alt`;
- локальные ресурсы в `src`, `href`, `poster` и `srcset`;
- ссылки на несуществующие якоря внутри страницы.

Пустой `alt=""` отмечается предупреждением, а не ошибкой: так можно обозначать декоративные изображения, которые не должны озвучиваться скринридером.

Код завершения 0 означает, что ошибки не найдены. Код 1 означает, что нужно исправить найденные ошибки. Скрипт не заменяет ручную проверку дизайна, мобильной версии, клавиатурной навигации и Lighthouse.
